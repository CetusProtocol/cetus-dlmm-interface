# Cetus DLMM Router Interface

This package exposes the public Move API of the Cetus DLMM router without its implementation.

```toml
[dependencies]
dlmmrouter = { git = "https://github.com/CetusProtocol/cetus-dlmm-interface.git", subdir = "packages/dlmm-router", rev = "<revision>" }
```

The package uses Sui's modern package system. Its published mainnet and testnet addresses are recorded in `Published.toml`.
